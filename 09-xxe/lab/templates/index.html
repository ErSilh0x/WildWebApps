WildParts Store

The store's Check stock feature parses an XML document you control with an unsafe parser that resolves external entities. Declare an entity that points at a local file (file:///etc/passwd), reference it inside <productId>, and the parser reads that file into the document. The lookup then fails and the app quotes your value back in an error message: that error is where the file (and the MD5 flag) leaks out. This is error-based exfiltration.
