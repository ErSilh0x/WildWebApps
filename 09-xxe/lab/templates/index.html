▸ Training notes - XML External Entity (XXE) · A05:2025 · click to expand

The stock API parses the XML you submit with a parser that resolves external entities. Declare an entity that points at a local file (file:///etc/passwd) and reference it inside <productId>: the parser reads the file into the document, the lookup then fails, and the app quotes your value back in the error. That error is where the file (and the planted secret) leaks out. This is error-based exfiltration.
