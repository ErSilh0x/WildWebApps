WildFiles Portal

A small account portal with three real file-operation sinks. Each loads a file named by your input, joining it onto a base directory and reading it with no confinement check. Escape a base directory (relative ../ climb or an absolute path) to read the MD5 flag in .env_backup, a backup env file kept outside the web root, then submit it below.
