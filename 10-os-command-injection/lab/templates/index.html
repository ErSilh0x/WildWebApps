▸ Training notes - OS Command Injection · A05:2025 · click to expand

The Ping tool builds a shell command out of the target host you submit (ping -c 1 <host>) and runs it through /bin/sh. Because the value is dropped straight into a command line, a shell metacharacter lets you chain a second command: a value like 127.0.0.1; cat /root/secret.txt runs the ping and then reads a file it never should. The recoverable secret is a 32-char value stored in /root/secret.txt.
